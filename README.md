# 🛡️ Cyber Incident Response Dashboard

A beginner-friendly cybersecurity dashboard designed to simulate the process of reporting, tracking, investigating, and managing cybersecurity incidents.

## 📌 About the Project

The Cyber Incident Response Dashboard is a frontend-based cybersecurity project created using HTML, CSS, and JavaScript.

It provides a simple interface for recording security incidents, assigning risk levels, tracking investigation status, managing evidence checklists, and generating incident reports.

All incident data is stored locally in the browser using Local Storage.

## 🚀 Features

- 📝 Report cybersecurity incidents
- ⚠️ Assign risk levels
- 🔄 Update incident status
- 🔍 Search incidents by name or type
- 📊 Risk summary dashboard
- 📋 Evidence collection checklist
- 🕒 Incident response timeline
- 📄 Download incident reports
- 🗑️ Delete incidents
- 💾 Local Storage data persistence
- 🖥️ System status monitoring
- 📱 Responsive dashboard design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🔐 Incident Types

The dashboard supports different types of cybersecurity incidents, including:

- Phishing
- Malware
- Unauthorized Access
- Data Breach
- Social Engineering
- Other

## 📊 Risk Levels

Incidents can be classified as:

- Low
- Medium
- High
- Critical

## ⚙️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start reporting and managing incidents.

No PHP, MySQL, XAMPP, or backend server is required.
